# 2封装绘制
1. 点击快速开始里面的新建封装
![[Pasted image 20260109183307.png]]
2. 填写元器件封装信息，
![](file:///C:\Users\21196\AppData\Local\Temp\ksohtml15248\wps6.jpg) 

3. 绘制焊盘（点击放置-焊盘-鼠标点击页面放置焊盘），根据数据手册的封装设计或者实物，确定焊盘的数量，形状和焊盘间的间距
![[Pasted image 20260109183531.png]]
4.  点击焊盘修改焊盘的参数比如每个焊盘的大小，通过智能尺寸焊盘的间距进行位置的更改（选工具-智能尺寸-然后选中两个点及可测量间距和焊盘大小），注意在绘制焊盘的时候一般要加宽1倍方便焊接，然后通过对齐方式调整
 5. 对齐快捷键：
- Ctrl+Shift+L 左对齐
- Ctrl+Shift+R 右对齐
- Ctrl+Shift+O 顶部对齐
- Ctrl+Shift+B 底部对齐
- Shift+Alt +E 左右居中对齐
- Shift+Alt +H 上下居中对齐
![[Pasted image 20260109183845.png]] 
等距分布快捷键：
- Ctrl+Shift+H 水平等距分布
- Ctrl+Shift+E 垂直等距分布
![[Pasted image 20260109191348.png]]
3. 鼠标左键单击空白区域-在右边菜单栏点击切换到顶层丝印层，点击放置-线条，然后修改合理的线宽后同样通过智能尺寸调整丝印位置，注意丝印不能和焊盘重叠
![[Pasted image 20260109191954.png]]
 

# 3符号绑定封装

1. 点击下面菜单栏的库-在下方的库中选择个人-选择分类-找到刚刚绘制的元器件符号-右键选择编辑器件
![[Pasted image 20260109192748.png]]
 

2. 在左边库设计-属性-封装-右边3个点
![[Pasted image 20260110234901.png]]
3. 在封装管理器中，确认位号（1）是否选择-在2中找到刚刚保存封装的位置-在3中选中封装-在4可以查看封装的大小间距等如果需要修改可以点击🖊修改封装-5点击确认
![[Pasted image 20260110235943.png]]
4. 封装后面显示出就说明绑定成功了
